# TABI — Япония вдвоём

Мобильный планировщик поездки: основной маршрут и 5 альтернатив, 120 дневных программ, Google Maps, 28 фотографий, фотоистории, отели и транспорт, ссылки на бронирования.

## Общий бюджет

Во вкладке «Покупки» нажмите «Создать общий бюджет», затем откройте личную ссылку на втором устройстве. Суммы и отметки синхронизируются через Supabase примерно каждые 5 секунд, пока сайт открыт; собственные изменения отправляются сразу. При одновременном редактировании одной покупки приложение показывает конфликт и загружает актуальное состояние вместо молчаливой перезаписи.

Личная ссылка даёт доступ к бюджету. Секрет находится во фрагменте URL и локальном хранилище; в репозитории и публичных файлах его нет. Не публикуйте личную ссылку. Без подключения к общей поездке отметки сохраняются только в браузере. JSON-экспорт/импорт — резервная копия. Очистка данных браузера удаляет локальные отметки и сохранённое подключение; облачную поездку можно вновь открыть по личной ссылке.

## Разработка

Node.js 22.13+ и pnpm 11.19.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build --base /japan-travel/
pnpm preview
```

## Публикация

GitHub Actions автоматически собирает сайт после push в main. В Settings → Pages выбран источник GitHub Actions. Путь ресурсов берётся из configure-pages, поэтому фотографии и ссылки работают под путём репозитория.

Настройка общей базы: [supabase/README.md](supabase/README.md). В app/cloud-config.ts допустимы только публичный URL проекта и publishable key; service-role/secret ключи сюда добавлять нельзя. SQL блокирует прямой доступ к таблицам и проверяет секрет комнаты внутри RPC.

Ограничения бесплатной базы, включая возможную паузу неактивного проекта, определяются текущим тарифом Supabase. Перед поездкой откройте сайт и проверьте синхронизацию.

## Источники

Фото и лицензии перечислены в app/photo-catalog.json и внизу сайта. Фотографии принадлежат указанным авторам и используются по их лицензиям. Полный купленный гайд в репозиторий не включён; оставлены ссылки на источники.

Цены — проверка 7–8 сентября 2026, на двоих; котировки не фиксируют наличие и цену бронирования. Комиссии и фактические суммы могут отличаться.

Технические инструкции: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [Vite](https://vite.dev/guide/static-deploy#github-pages), [Supabase API keys](https://supabase.com/docs/guides/getting-started/api-keys).
